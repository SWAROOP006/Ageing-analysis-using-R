# Ageing-analysis-using-R
Bioinformatics research on ageing hypothesis based on the chromosomal sequences and specific nucleotide repeats in various organisms using sequin package in R programming for analysis.
## Telomere Repeat Analysis in Multiple Organisms

🧬 This repository presents my B.Tech thesis project, where I analyzed telomeric repeat patterns (TTAGGG and variants) in the genome of 28 organisms using R.

## 📂 Included Files
- **B.Tech Thesis.pdf**: Full report including methodology, literature review, and results
- **telomere_repeat_analysis.R**: R script used to detect telomeric repeat positions and generate plots

## 🔧 Tools Used
- R programming language
- `seqinr` package in R
- Genomic FASTA files from NCBI

## 🔍 Summary
- Focused on repeats: TTAGGG, GGGATT, AATCCC, and CCCTAA
- Analyzed both forward and reverse strands
- Visualized repeat counts using histograms
- Results indicate conserved presence of repeats across diverse phyla

## 📊 Key Organisms
- Drosophila, C. elegans, Human, Whale, Cat, Dolphin, Honeybee, Panda, etc.

## 📈 Findings
- Internal telomeric repeats are conserved across species
- Differences in repeat distribution suggest evolutionary roles
- Data may help in future synthetic biology and aging research
